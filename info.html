Cómo funciona

Un único enlace, una única versión

Este portal está pensado para evitar copias, PDFs desactualizados y enlaces dispersos. Cuando un recurso cambie, se actualizará aquí el acceso vigente.

La web no guarda datos personales

Los recursos que requieran control de acceso permanecen alojados fuera de GitHub y protegidos mediante los permisos de Canva u OneDrive.

GitHub Pages como portal

El repositorio contiene únicamente la interfaz, el horario y los enlaces que queramos publicar. El historial de Git permite recuperar cambios anteriores.

Enlaces estables

Conviene mantener el mismo vínculo externo cuando se sustituya un documento. Así no hay que cambiar la web cada vez que exista una nueva versión.

Diseñado para móvil

La navegación, el horario y los accesos están optimizados para consultar las jornadas desde el teléfono en pocos segundos.
